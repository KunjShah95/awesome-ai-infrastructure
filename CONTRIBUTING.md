# Contributing

This list is **generated** from the [Lattice](https://lattice.kkshah2005.workers.dev) dataset, so it never drifts
from the site. Edits to `README.md` here are overwritten on the next sync.

## Corrections (most welcome)

Wrong licence, wrong cost model, a skip-when sentence that is unfair or out of
date, a tool that has shut down: open an issue with a link to the source that
shows it. Licence and cost facts are re-checked on a schedule the site's build
enforces ([the receipt](https://lattice.kkshah2005.workers.dev/verification.json)), and a confirmed correction ships
in the next sync.

## Suggesting a tool

Open an issue with:

1. The tool and its repository or homepage.
2. The layer it belongs to.
3. **When you would use it, and when you would not.** An entry without a
   credible "skip when" does not go in.

A suggestion becomes an entry only if it clears the same bar as everything
already listed. See [the methodology](https://lattice.kkshah2005.workers.dev/methodology), including the section on
where this list is wrong.

## What will not be accepted

- Paid placement or vendor-submitted ranking.
- Star counts, or ordering by popularity.
- AI end-user apps. This is infrastructure for building them.
